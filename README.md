# Калькулятор поездок

Статический калькулятор на HTML, CSS и Vanilla JavaScript. Tailwind CSS и Telegram Web App SDK загружаются через CDN. Устанавливать зависимости и собирать проект не нужно.

## Локальный запуск

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Для доступа к системному буферу обмена используйте localhost или HTTPS. Если браузер отклонит копирование, приложение покажет код для ручного ввода.

## Настройка перед публикацией

- В `config.js` замените `promo.code` и `promo.url` на действующий реферальный промокод на 500 бонусов и HTTPS-ссылку приложения или бота. После проверки установите `promo.demo` в `false`. По умолчанию показан `DEMO500`, а ссылка ведёт на официальную страницу скачивания.
- В `tariffs` отредактируйте допущения для «Эконома» и «Комфорта». Параметры `insurance` и `wash` заданы в рублях за месяц. Значение `deli.fixedPerTrip` задаёт фиксированную цену за одну поездку. Оставьте `null` для расчёта по минутам.
- Месяц равен `52 / 12` недели. Дневной пробег суммарный, по умолчанию он приходится на две поездки. Время оценивается из средней скорости 28 км/ч. Тарифы иллюстративные, бонусы в месячном сравнении не учитываются.

## GitHub Pages

1. Загрузите файлы проекта в корень ветки `main` своего репозитория.
2. В `Settings → Pages` выберите `Deploy from a branch`, ветку `main` и папку `/(root)`. Сохраните настройку.
3. Откройте HTTPS-адрес из настроек Pages. Для запуска в Telegram укажите этот адрес в настройках Mini App или кнопки меню бота через `@BotFather`.

Документация по [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) и [Telegram Mini Apps](https://core.telegram.org/bots/webapps).
